# Louise Rever サイト

和歌山県海南市のエステサロン「Louise Rever」のサイト。
`https://www.louiserever.com/` の静的コピーを出発点に、レスポンシブ1本化まで改修したものです。

コピー取得日: 2026-08-04

---

## ⚠️ 公開先へ同期する前に必ず読むこと

**`site/cgiFolder/` を同期対象から除外してください。**

予約フォームの送信先 `cgiFolder/mail_send.php` は**サーバー側のPHPで、このリポジトリに存在しません**。
静的コピーでは取得できないためです（`POST` すると 501 が返ります）。

このリポジトリをそのまま公開先に上書き同期すると、**`cgiFolder/` ごと置き換わって
`mail_send.php` が消え、全15ページが掲げている「Web予約 24時間受付」が1件も届かなくなります。**
表示は正常に見えるため、気づくまでに時間がかかります。

同期の対象は `site/` 配下から `cgiFolder/` を除いたもの、という前提で運用してください。

あわせて、予約フォームには次の未対応があります（`mail_send.php` を回収してから着手する項目）。

- 送信先メールアドレスが hidden で客側から送られている（base64。復号すると `info@louiserever.com`）
- CAPTCHA / CSRF トークン / ハニーポットが 0 件
- `action="javascript:TW_confirm(...)"` で確認画面をクライアント側に持っている

## 起動方法

相対パス（`../assets/` など）で組まれているため、`file://` ではなく HTTP で開いてください。

```sh
cd site
python3 -m http.server 8899
```

トップ: http://127.0.0.1:8899/index.html

ウィンドウ幅を変えると追従します。`/sp/` は PC 版へ転送されます。

## 構成

現役は **PC版15ページのみ**です。レスポンシブ1本で全ての幅に対応します。

```
site/
├── index.html            トップ
├── beginner/             初めての方へ
├── trial/                トライアル
├── course_plan/          コース・プランのご案内
├── how_to_choose/        コース・プランの選び方
├── faq/                  よくある質問
├── campaign/             キャンペーン
├── shopinfo/             店舗のご案内
├── singlefolder/         スタッフ紹介6ページ・予約フォーム
├── css/
│   ├── lr-common.css     ★ 改修はすべてここ（2,516行 / 106KB）
│   ├── site.css          生成CSS ― 編集しない
│   └── G0000000xx/       生成CSS（ページ群ごと） ― 編集しない
├── js/
│   ├── lr-reveal.js      ★ 出現（印を付けるだけ。いつ出すかはCSSが持つ）
│   └── lr-schedule.js    ★ 営業日カレンダー（定休日を規則から算出）
├── assets/               画像 108点 / 2.8MB
├── cgiFolder/            生成JS・corestyle.css ― 編集しない／同期しない
└── sp/                   退役済み。PC版へ転送するだけ（noindex）
```

全646ファイル / 6.6MB。

### sp/ の扱い

PC版が全幅対応したため、SP版15ページは役目を終えています。
中身は消さず、`<head>` 先頭に PC版への転送を入れ、`noindex` を付けてあります。

削除するときは **先にサーバー側で `/sp/(.*)` → `/$1` の301を張ってから**にしてください。
順序を逆にすると、既存の被リンクとブックマークが404になります。

## 編集の約束ごと

### 触らないもの

生成CSS（`css/site.css` / `css/G*/cssfiles/*` / `cgiFolder/corestyle.css`）は**編集しません**。
ブロックID（`B000000xxx`）が HTML・CSSファイル名・JS初期化・解析タグまで貫通しているため、
生成物を直接触ると次の再生成で失われます。

上書きは `css/lr-common.css` に、**同じか一段上の詳細度で**書きます。
このファイルは `<head>` の最後に読み込まれるので、同詳細度なら後勝ちで効きます。

### 使ってよい寸法・色

このサイトの造形は実測から出た次の語彙で組まれています。新しい数を増やさないでください。

| | |
| --- | --- |
| 余白 | 5 / 10 / 15 / 20 / 30 / 40 / 50 / 100 / 150 |
| 箱の高さ | 50 / 40 / 30 |
| 級数 | 28 / 26 / 24 / 22 / 20 / 18 / 16 / 15 / 13 / 12（狭い幅では一段下げる） |
| 行送り | 1.7 |
| 字送り | 0 |
| グリッド | 1000 = 300×3 + 50×2 |
| 色 | `#D9C79D` `#C4A764` `#BC9C52` `#70592C` `#F3EDE2`（内側の仕切りは `#E4D6B2`） |
| 線の意味 | **1px = 仕切る（押せない） / 2px = 押せる** |
| 動き | 操作への返事 200ms / 線が引かれる 500ms。`--lr-t` `--lr-t-draw` `--lr-e` `--lr-e-draw` |

**レイアウト目的の `!important` は使いません。** 現在 `lr-common.css` にある7件は
すべて `prefers-reduced-motion` の中（アクセシビリティ上の正しい用法）です。

### 改行コード

HTML は全て **CRLF** です。スクリプトで編集するときは必ず `newline=''` を指定してください。
一度これを落として差分が1,750行に膨らんだことがあります。

### 折り返す幅

新しい breakpoint を作らず、次の2つだけを使います。どちらもこのサイト自身が持っていた数です。

- **1040px** — 版面1000 + 左右の余白20×2。これ以下で版面が流動する
- **640px** — サイトが `rel="alternate"` で宣言していた「ここからは携帯」の境目

## 検証

`site/` を配信した状態で、ヘッドレス Chrome で次を機械的に確認しています。

| 検査 | 範囲 | 結果 |
| --- | --- | --- |
| 版面・ナビの段数・罫・本文の可視性・下端の帯・横のはみ出し・**要素の重なり** | 15ページ × 12幅（320〜1440px）= 180組 | 問題 0 |
| 内部リンクの解決（絶対URLを含む） | 596本 | 問題 0 |
| 画像の実在 | 367枚 | 不在 0 |
| CRLF | HTML 30ファイル | 維持 |
| JS エラー | 主要ページ | 0 |
| CSS 構文（括弧の対応・注釈混入セレクタ） | lr-common.css | 問題 0 |

**「重なり」の検査は要素単位ではなく文字の行box単位**で測っています。
要素の矩形で測ると、float の隣にある段落が必ず誤検出されるためです。
畳んだアコーディオンの中身と読み上げ専用の隠し文字は、切り抜かれている要素として除外します。

この検査を入れる前、**ヘッダーの3要素が全ページ・640px以下で重なっていました**。
右端を越えたかどうかだけを見ていたため、重なりは1pxも幅を超えず、どの検査にも掛かりませんでした。
